# Quartermaster

Quartermaster is a personal historical research and wargaming asset catalog.

Its first purpose is not to store files. It helps users know what they own, what each item is about, and where their physical or digital copy lives.

## Early Scope

- Catalog creators, publishers, packages, books, documents, models, maps, photos, and other assets.
- Track user ownership separately from shared catalog metadata.
- Record local, NAS, cloud, archive, and physical locations.
- Support one-to-many tags for items, files, packages, books, and personal notes.
- Handle standalone historical documents as well as bundled STL packages.
- Model complex STL assets made from multiple components.

## Proposed Stack

- Vue
- Vite
- Vuetify
- Supabase Auth
- Supabase Postgres with Row Level Security
- Supabase Storage as a later optional stage

## Working Name

Quartermaster is the current working name. It fits digital assets, books, documents, miniatures, and research collections without making the app sound STL-only.
